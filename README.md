# Fysiklabbet: frisläppta nationella prov

Pdf-filer som sidan [Nationella prov](https://fysiklabbet.se/np.html) länkar till.
De ligger i ett eget repo så att huvudsajten håller sig under GitHub Pages
gräns på 1 GB.

- `pdf/ma1b-…-delprov-b.pdf` osv.: elevhäftena per delprov i Ma 1b och 1c
  (källa: PRIM-gruppen, Stockholms universitet).
- `pdf/ma2c-vt22.pdf` osv.: delprov B–D i Ma 2b, 2c, 3b, 3c och 4, utan
  bedömningsanvisningarna (källa: Umeå universitet).

Bilderna i filerna är nedskalade (längsta sida 1 300 px, JPEG) för att hålla
storleken nere. Listan över proven bor i `data/np/frislappta.js` i repot
Fysiklabbet.
